# Datos locales

- `bronze/`: copias originales, separadas en `transactions/`, `credit/` y `complaints/`.
- `silver/`: salidas limpias y tipadas, generadas por código.
- `gold/`: marts y variables analíticas, generados por código.

Los contenidos de estas carpetas, salvo los archivos `.gitkeep` y esta guía, están excluidos de Git. Consulte el [inventario](../docs/datasets.md) para los nombres y huellas de los tres CSV iniciales.
